# 말투 — 토스처럼 쉽고 깔끔하게

이 스킬은 어려운 내용을 남에게 쉽게 전하려고 만든 스킬이에요. 그런데 그림이 아무리 화려해도 문장이
번역체면, 읽는 사람은 문장을 해석하느라 내용을 놓쳐요. 실제로 "도표만 화려하고 말은 더 어렵다"는 평을
받았어요. 그래서 **문장 규칙이 디자인 규칙보다 먼저**예요.

목표는 토스 앱의 말투예요. 쉽고, 바로 이해되고, 군더더기가 없어요.

## 기본

- **해요체로 써요.** `~해요 · ~이에요 · ~예요 · ~돼요 · ~했어요`. 합니다체(`~습니다`)는 쓰지 않아요.
  원문 인용(`q`)은 원문 그대로 두고, 우리가 쓰는 문장(쉬운 말 · 태그 · 캔버스 표지 · 부록 설명)만 해당해요.
- **한 문장에 한 생각.** 캡션은 1–2문장, 한 문장은 40자 안팎.
- **핵심부터.** 결론을 먼저, 이유는 그다음에.
- **사람이 주어, 능동형, 동사로.** "~가 이뤄져요"보다 "~를 해요".
- **평소에 말하는 낱말.** 어려운 용어는 처음 한 번만 풀고, 그다음엔 그대로 써요.
- **소리 내어 읽어 봐요.** 친구에게 말로 설명할 때 이렇게 말하지 않을 문장이면 다시 써요.

## 쓰지 않는 문장 — 번역체 · AI 말투

| 버릇 | 나쁜 예 | 고친 예 |
|---|---|---|
| 화면 해설로 시작하기 | 이 그림에서 흩어져 있던 점이 모두 첫 선에서 뻗어 나간 선 위에 줄을 섭니다. | 흩어져 있던 점이 첫 선을 따라 줄을 서요. (꼭 필요할 때만, 짧게) |
| 무생물 주어 · 의인화 | 두려움이 내 걸음을 대신 정하게 두지 않는 것. | 두려워도 내 일은 내가 정하면 돼요. |
| 명사로 끝나는 조각문 · 대시로 잇기 | 온 정신을 모아 곧게 쏜 한 번. / 마음을 모으고 — 모든 일의 시작입니다. | 온 정신을 모아 곧게 쏘는 한 발이에요. |
| 틀 문장 남발 | ~하는 것입니다. ~라는 뜻입니다. ~하는 순간입니다. | 동사로 바로 끝내요. "~해요." |
| "A에서 B로 바뀝니다" 추상 변환 | 죽음은 떠받들던 무서운 신에서 그냥 일어나는 일 하나로 바뀝니다. | 죽음은 떠받들 무서운 존재가 아니라, 언젠가 일어나는 일일 뿐이에요. |
| 한자어를 억지로 풀어 길게 | 세상 모든 것의 모양을 자유롭게 그려 냅니다. | 세상 만물을 자유롭게 그려요. |
| 영어 직역 표현 | ~에 관하여, ~을 통해, ~에 있어서, ~를 가지다, ~로 해석될 수 있습니다 | ~에 대해, ~로, ~에서, ~가 있다, ~예요 |
| 보고서 문장 그대로 옮기기 | 밸류에이션 부담이 상방을 제한하는 요인으로 작용합니다. | 이미 비싸서 더 오르기 어려워요. |
| 신호를 어렵게 말하기 | RSI가 과매도 구간에 진입하여 매도 압력의 과도함을 시사합니다. | RSI가 30 아래로 내려갔어요. 너무 많이 팔렸다는 신호예요. |
| 지어낸 꼬리표 말 | 그런 날을 「큰 밤」이라 부르면 | 종가까지 10% 넘게 더 오른 날 세 번 (무엇이 · 얼마였는지 그대로) |

이것도 쓰지 않아요.

- 직업 비유(개발 · 프론트엔드 개념에 빗대기).
- 제작 메모: "이 페이지는 ~을 보여 줍니다", "쉽게 읽히도록 썼어요", 청중 꼬리표("임원이 물을 질문").
- 유보 표현: "아마", "참고용", "확실하지 않지만". (투자 권유가 아니라는 말은 첫 장면에 한 번만.)

## 다 쓰고 나서 검사

```bash
# 번역체 버릇
grep -n -E "이 그림에서|이 그림의|것입니다|라는 뜻입니다|순간입니다|에 관하여|을 통해|에 있어서|로 해석될" src -r
# 합니다체가 남은 쉬운 말 · 태그
grep -n -E "(plain|tag|lead|title): \"[^\"]*(습니다|입니다|됩니다|합니다)" src -r
```

두 줄 모두 0이 될 때까지 고쳐요. 마지막으로 캡션만 처음부터 끝까지 소리 내어 읽듯 한 번 읽어요.
읽다가 멈칫하는 문장이 있으면, 그 문장은 아직 번역체예요.
